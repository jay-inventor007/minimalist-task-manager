## Overview

A focused, single-purpose task management interface built to eliminate clutter and provide seamless local productivity:
- **Instant Task Creation & Completion:** Add, complete, and delete action items with zero friction.
- **Priority Categorization:** Visual status indicators for urgent, active, and completed objectives.
- **Persistent Local State:** Automatically syncs tasks to the browser's localStorage, preserving todo lists across sessions without accounts or network reliance.
- **Pure Zero-Dependency Stack:** Built with pure HTML5, CSS3, and JavaScript—loads instantly with zero bundle overhead.

## Quickstart

Run directly in any browser:

```bash
# Clone the repository
git clone https://github.com/jay-inventor007/minimalist-task-manager.git
cd minimalist-task-manager

# Open in your browser
start index.html
```
